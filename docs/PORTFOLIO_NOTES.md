# Portfolio Notes

## Recommended GitHub repository name

`hotel-reservation-android-app`

## Suggested portfolio description

A native Android hotel reservation application built with Java and Firebase, featuring role-based user and administrator workflows, room management, booking, payment integration, and real-time notification capabilities.

## Important

Do not upload:
- google-services.json
- .firebaserc
- API keys
- payment credentials
- service-account credentials
- generated build folders
